# 방구석 — 원룸 리뷰 서비스

살아본 사람만 아는 정보를 남기는 원룸 리뷰 서비스입니다.
방을 구할 때 발품만으로는 알기 어려운 것들 — 채광, 방음, 수압, 벌레, 습도, 집주인 —
을 이전 거주자의 리뷰로 확인할 수 있습니다.

## 실행

빌드나 설치가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

```bash
# 리뷰 저장(localStorage)까지 확인하려면 로컬 서버로 여는 편이 확실합니다
python -m http.server 8000
# http://localhost:8000
```

## 기능

- **지도 첫 화면** — 성균관대 캠퍼스타운의 원룸이 평점 핀으로 표시됩니다.
  드래그로 이동, 휠로 확대·축소, 핀을 클릭하면 해당 방의 리뷰 화면으로 이동합니다.
  핀 색으로 평점대를 구분합니다 (4.5+ 초록 / 4.0+ 라일락 / 3.0+ 노랑 / 그 미만 빨강).
- **별점** — 0점부터 5점까지 0.5점 단위. 진한 노란색으로 표시됩니다.
- **항목별 평점** — 채광·방음·수압·벌레·습도/단열·관리/집주인 6개 항목을 따로 평가합니다.
- **리뷰 작성** — 같은 0.5단위 별점 입력기와 태그, 거주 기간, 거주 인증 여부.
  작성한 리뷰는 브라우저의 localStorage에 저장됩니다.
- **열람권** — 읽기만 하는 이용자가 늘지 않도록, 거주자 리뷰 본문은 하나씩 열람권 1개로 열립니다.
  가입 시 20개를 지급하고, 실거주 인증 리뷰를 한 번 작성하면 이후 무제한입니다.
  항목별 평점·기본 정보·태그 같은 요약 정보는 열람권 없이 볼 수 있습니다.
- **그 외** — 전체 목록, 평점 랭킹, 관심 목록, 내가 쓴 리뷰, 검색·필터·정렬,
  도움돼요, `#/room/r1` 형식의 공유 가능한 링크.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대와 SVG 지도 |
| `styles.css` | 디자인 시스템 (색·타이포·컴포넌트) |
| `data.js` | 매물·리뷰 데이터 |
| `app.js` | 렌더링, 지도 상호작용, 라우팅, 저장 |

## 참고

- 지도는 외부 API 없이 직접 그린 SVG입니다. 인터넷 연결이나 API 키가 필요 없습니다.
- 건물명과 주소, 리뷰는 예시용 가상 데이터입니다.
- 실제 지도로 바꾸려면 SVG를 Leaflet/카카오맵으로 교체하고
  `data.js`의 `x`/`y` 좌표를 위경도로 바꾸면 나머지 로직은 그대로 쓸 수 있습니다.
